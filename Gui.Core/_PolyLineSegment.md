# PolyLineSegment Class

## namespace [Noesis](/Gui.Core/_ClassHierarchy.md#noesis-namespace) | [MSDN](https://docs.microsoft.com/en-us/dotnet/api/system.windows.media.polylinesegment)

Represents a set of line segments defined by a PointCollection with each Point specifying the end point of a line segment.
