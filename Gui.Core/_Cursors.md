# Cursors Class

## namespace [Noesis](/Gui.Core/_ClassHierarchy.md#noesis-namespace) | [MSDN](https://docs.microsoft.com/en-us/dotnet/api/system.windows.input.cursors)

Defines a set of default cursors.

This static class defines a set of default cursors common to applications.
