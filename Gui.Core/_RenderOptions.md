# RenderOptions Class

## namespace [Noesis](_ClassHierarchy.md#noesis-namespace) | [MSDN](https://learn.microsoft.com/en-us/dotnet/api/system.windows.media.renderoptions)

Provides options for controlling the rendering behavior of objects.

You can use the attached properties of the [RenderOptions](_RenderOptions.md) class to specify options for the rendering of text and visual elements in your application. These options enable you to optimize rendering for speed or quality.
