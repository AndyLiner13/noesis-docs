# Methods

| Name | Description |
| --- | --- |
|  *ClearAllBindings(target)* | Removes all bindings from the specified [DependencyObject](../Gui.DependencySystem/_DependencyObject.md) |
|  *ClearBinding(target, dp)* | Removes the binding from a property if there is one |
|  *GetBinding(target, dp)* | Retrieves the [Binding](_Binding.md) object that is set on the specified property |
|  *GetBindingBase(target, dp)* | Retrieves the BindingBase object that is set on the specified property |
|  *GetBindingExpression(target, dp)* | Returns the [BindingExpression](_BindingExpression.md) object associated with the specified binding target property on the specified object |
|  *GetBindingExpressionBase(target, dp)* | Returns the [BaseBindingExpression](_BaseBindingExpression.md) object associated with the specified binding target property on the specified object |
|  *IsDataBound(target, dp)* | Returns a value that indicates whether the specified property is currently data-bound |
|  *SetBinding(target, dp, binding)* | Creates and associates a new instance of [BaseBindingExpression](_BaseBindingExpression.md) with the specified binding target property |
