# LinearRectKeyFrame Class

## namespace [Noesis](/Gui.Core/_ClassHierarchy.md#noesis-namespace) | [MSDN](http://msdn.microsoft.com/en-us/library/system.windows.media.animation.linearrectkeyframe.aspx)

Animates from the *Rect* value of the previous key frame to its own *Value* using linear interpolation.

This class is used as part of a [RectKeyFrameCollection](/Gui.Animation/_RectKeyFrameCollection.md) in conjunction with a [RectAnimationUsingKeyFrames](/Gui.Animation/_RectAnimationUsingKeyFrames.md) to animate a Rect property value along a set of key frames.

A key frame defines a segment of the [RectAnimationUsingKeyFrames](/Gui.Animation/_RectAnimationUsingKeyFrames.md) to which it belongs. Each key frame has a target Value and a [KeyTime](/Gui.Animation/_KeyTime.md). The [KeyTime](/Gui.Animation/_KeyTime.md) specifies the time at which the key frame's Value should be reached. A key frame animates from the target value of the previous key frame to its own target value. It starts when the previous key frame ends and ends when its own key time is reached.

Linear key frames like [LinearRectKeyFrame](/Gui.Animation/_LinearRectKeyFrame.md) create a smooth, linear interpolation between values.
